## Permissions declaration

The merged release manifest contains:

- `android.permission.INTERNET`
- An application-scoped dynamic-receiver permission generated by Android

It does not request camera, precise/approximate device location, contacts, SMS,
call log, microphone or broad storage permissions. File selection uses the
system picker. No high-risk permission declaration should be required.

## AI-generated content

The Clawd feature sends selected operational data and user prompts through a
server-side Supabase Edge Function to an AI service. It is restricted to
authorized administrative/accounting use. Confirm any AI-generated-content
declaration presented by Play Console and ensure reviewer access includes this
  feature if it is available in the Android build.
